# Voice Router frontend

Next.js App Router UI. Setup, speech providers, tests and API contracts are documented in the [repository README](../README.md) and [SPEC](../docs/SPEC.md).

Native: `npm ci && npm run dev`. Production: `npm run build && npm start`. `NEXT_PUBLIC_API_URL` defaults to http://localhost:8080 and is fixed at build time. `npm run lint` checks the source.
