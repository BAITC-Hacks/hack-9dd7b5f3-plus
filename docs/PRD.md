# Voice Router / Plus

Клиент вымышленной страховой компании говорит на русском, казахском или смешивает языки. LLM выбирает сценарий по смыслу и истории. Супервизор наблюдает транскрипт, публичное объяснение выбора, альтернативы, параметры и задержки.

P0: голосовой ввод/ответ, текстовый резерв, каталог из стартового кита, контекст до 10 реплик, проверяемый JSON маршрута, уточнение/оператор, live trace, запуск одной командой, mock без ключей. P1: потоковая транскрипция, потоковый PCM TTS, аудио-оценка p50/p95 и точности, сохранение сессий в PostgreSQL.

Демо: вопрос о полисе → смена темы на выплату → возврат к полису; показать выбор и границу соседнего сценария, загрузить аудиофайл, скачать трассу.

Никаких реальных банковских/страховых операций. Ответы основаны на каталоге и синтетических фактах. Mock — тестовый дубль, не LLM и не доказательство качества маршрутизации.

Стартовый кит и evaluate.py отсутствовали при начале реализации. Встроенные сценарии — явно синтетические, не подмена исходных сорока. Сравнение с baseline возможно только после получения кита и ключа выбранного провайдера.

Цели измерений: routing p50/p95 ≤500 мс; конец речи → первое воспроизводимое аудио ≤1500 мс. Не выдаём скорость mock/загрузки файла за real-time latency.
